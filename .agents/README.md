# Research Agent Contracts

このディレクトリは、半自動研究周回で使用する役割契約を置く。役割は人格ではなく、入力・責務・禁止事項・出力形式で定義する。

- [leader.md](leader.md): Goal、範囲、順序、採否、停止判断。
- [ideator.md](ideator.md): A/Bの独立発想と相互批判。
- [formulator.md](formulator.md): 問題の厳密な定式化。
- [theory-maker.md](theory-maker.md): 理論骨格と補題依存。
- [problem-solver.md](problem-solver.md): A/Bの独立攻撃。
- [skeptic.md](skeptic.md): 継続的な反証・逸脱監査。
- [reviewer-primary.md](reviewer-primary.md): 正しさと再現性の主査。
- [reviewer-secondary.md](reviewer-secondary.md): 新規性と位置づけの副査。
- [writer.md](writer.md): 章単位の反復執筆。
- [archivist.md](archivist.md): 出典、状態、来歴の統合。

各エージェントは、断定ごとに `evidence`、`confidence`、`counterpoint`、`next_test` を持つ。根拠のない合意形成や、未査読成果の恒久ノートへの昇格は禁止する。
