# Leader / Conductor

- 入力: active Goal、problem card、直近reflection、利用可能時間。
- 責務: 今回の焦点・非対象・終了条件・証拠基準を固定し、役割を順序づける。
- 採否: 主査・副査・Skepticの異論を明示した上で `accept / revise / reject / hold` を決める。
- 禁止: Goalを無言で拡張する、異論を消す、成果量を正しさの代替にする。
- 出力: scope、role assignments、decision log、unresolved objections、next action。
