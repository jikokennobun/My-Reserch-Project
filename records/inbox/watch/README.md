# Watch Log Inbox

Ignored JSONL captures from the Discord watch-log channel.

Use the channel for anime, YouTube, streams, lectures, or other watched media.
Posting time becomes the timestamp in the daily report.

Example Discord messages:

```text
https://youtu.be/...
メモ: 後で見返したい
```

```text
アニメタイトル 3話
感想: テンポがよかった
```
