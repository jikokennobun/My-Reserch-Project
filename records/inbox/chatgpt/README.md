# ChatGPT Pro Inbox

Ignored JSONL captures derived from ChatGPT Pro conversations.

Supported sources:

- ChatGPT data export ZIP or `conversations.json`
- copied `.txt` / `.md` conversation notes
- manual `-Text` snippets passed to `code/scripts/import-chatgpt-pro-ideas.ps1`

The importer writes review material to
`records/research-triage/chatgpt-pro-ideas-YYYY-MM-DD.md` and can append a
block to Obsidian `Research-memo/研究アイデアInbox.md`.

Do not commit raw private conversation captures.
