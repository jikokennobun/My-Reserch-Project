# Records

Logs and discussion history live here. This directory preserves process,
decisions, and source-handling history; durable mathematical claims should be
promoted into `../research/notes/`.

## Directory Roles

- `logs/`: operational logs, sync logs, and short dated project traces.
- `discussions/`: substantive Codex/Claude discussion and review records.

## Promotion Rule

A record is not a research note by itself. When a discussion contains a
definition, theorem idea, counterexample, or proof sketch, promote it into a
note that follows `../docs/research-note-quality-standard.md`.

The promotion should preserve:

1. source and date;
2. exact mathematical notation when available;
3. assumptions and uncertainty;
4. next verification task.

## Log Policy

Logs may be concise, but they must answer two questions:

- what changed;
- where the durable result now lives.

For automated Project or Drive imports, include the source status. If a link is
unreachable, record the failure mode without replacing the missing content by
guesswork.
