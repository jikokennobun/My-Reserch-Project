# 会話中心の自動研究を、Goalと研究オブジェクト中心へ再設計する

## Observed defect

- 既存のidea、open problem、discussion、PDF、Obsidian index、Drive relayは存在するが、一件の研究がどのGoalから始まり、どの査読を経て成果へ昇格したかを一貫して追いにくい。
- 自律議論の役割が一つのログ内にまとまり、発想者・懐疑者・主査・副査の独立性と責任範囲が弱い。
- 研究成果の反芻と、自動化システム自体の改善が恒常的な完了条件になっていない。
- 動機、テーマ、本人の研究意図、エージェントが持つ研究者像の根拠を置く正規場所がない。

## Evidence

- 2026-07-18の半自動研究システム再設計要望。
- `docs/codex-research-automation.md` はdiscussion loopを持つが、二名独立査読、章単位執筆、人物像仮説、改善実験の共通データ契約を持たない。
- 既存の `research/ideas/`、`research/open_problems.md`、`records/discussions/`、`artifacts/` が別々に成長している。

## Intended change

- `RESEARCH_SYSTEM.md` を人間とエージェントの共通窓口にする。
- `Goal → Idea → Problem → Cycle → Reviews → Chapter → Reflection` のID付き連鎖を導入する。
- 10種の役割契約、二名の独立査読、常設Skepticを分ける。
- arXiv/OpenAlexの候補収集、Drive fileId、Obsidian索引、GitHub Actionsを文献台帳へ接続する。
- 動機、判断理由、根拠付き研究者像、研究反芻、システム改善を別の正本へ置く。

## Why this should help

研究内容と自動化の来歴が混ざらず、どの主張が未確認・計算観測・査読済みかを追跡できる。役割の独立初稿により、同意の演出ではなく実質的な差分を残しやすくなる。

## Metric / expected observation

RSYS-001の一週間で次を測る。

- 一件のproblemを一周させるまでの人間の整理時間。
- 主査と副査で異なる有用な指摘が生じた件数。
- 自動収集候補のうちActive Goalに直接関係した割合。
- 根拠リンク切れ、状態不明、同一文献重複の件数。
- テンプレート記入が研究を助けた箇所と、単なる負担だった箇所。

## Risks and rollback

- リスク: 役割とテンプレートが多すぎて研究を遅くする。
- リスク: 同系統モデル二名の査読を真の独立査読と誤認する。
- リスク: 自動収集がノイズと自動コミット競合を増やす。
- rollback: `.github/workflows/research-intake.yml` を無効化し、`RESEARCH_SYSTEM.md` の入口利用を停止する。既存の `research/`、`records/`、`artifacts/` は移動していないため、旧運用へ戻せる。
